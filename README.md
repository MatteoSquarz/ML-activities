# Machine Learning activities
This collection of activities was developed for the Machine Learning course, part of the Computer Science Master's degree at the University of Padua (A.Y. 2025-2026).

## Contents

The collection includes Colab notebooks designed to:
- Demonstrate practical machine learning applications
- Deepen understanding of key ML concepts
- Provide hands-on experience with real-world implementations

The topics illustrated in the notebooks are:
- Adressing overfitting using pruning in decision tree ([link](notebooks/pruning_approaches_dt.ipynb))
- Effectiveness of preprocessing when using SVM ([link](notebooks/preprocessing_SVM.ipynb))
- Using Kernelized Ridge Regression for non-linear data ([link](notebooks/ridgeRegression_kernelTrick.ipynb))
- Denoising Autoencoder (DAE) for corrupted images ([link](notebooks/DAE_corrupted_images.ipynb))
- Bias-Variance Decomposition with Decision Trees and Bagging ([link](notebooks/bias-variance_ensemble.ipynb))
- Metrics for evaluating clustering ([link](notebooks/clustering_metrics.ipynb))
- Clustering Spotify songs using audio features ([link](notebooks/clustering_spotify.ipynb))
